상대 특성

다중 이동 사수 계열. 종이우산으로 이동하며 포킹하고, 다중 이동으로 탱커를 농락한다.

다중 이동 사수물리 피해마법 피해강제 제어표식중첩/강화광역

라인전 대응

공손리의 이동 경로를 쫓지 말고, 우산이 빠진 뒤 2스킬로 붙잡는다.

교전·한타

아군 딜러와 함께 공손리를 측면에서 압박하고, 이동기가 끊긴 순간 점사한다.

하지 말 것

공손리의 이동 경로를 따라가며 스킬을 낭비하는 것.

상세 스킬

4개

중국판 공식 스킬 설명입니다. 스킬명·쿨다운·수치는 패치에 따라 달라질 수 있으므로 게임 내 최신 설명을 우선하세요.

  1. 패시브

    晚云落

    쿨다운 0 · 소모 0

    普攻会对目标叠加枫之印记，叠满四层后对周围敌人造成100(+30%物理攻击)法术伤害，并对周围单位叠加一层印记。释放技能或收回纸伞的下次普攻后会追加一次普攻造成(30%物理攻击)物理伤害。 在释放技能后再次使用技能回归到纸伞的位置。手中没有纸伞时获得50点移速加成并缩短10%基础攻击间隔。

    물리 피해마법 피해표식중첩/강화
  2. 1스킬

    岑中归月

    쿨다운 8/7.5/7/6.5/6/5.5 · 소모 50

    阿离向指定方向瞬步，并将纸伞留在原地（如果纸伞在阿离手中）。

  3. 2스킬

    霜叶舞

    쿨다운 11/10.8/10.6/10.4/10.2/10 · 소모 60

    阿离旋转起操控纸伞飞旋（如果纸伞在阿离手中），击落飞行物对范围内敌人造成两段打击每段造成180/240/300/360/420/480（+65%物理加成）点法术伤害。

    마법 피해광역
  4. 3스킬

    孤鹜断霞

    쿨다운 25/20/15 · 소모 90

    阿离击退前方的敌人，造成250/375/500（+80%物理加成）点法术伤害，并将纸伞向指定方向掷出（如果纸伞在阿离手中）。

    마법 피해강제 제어
