  1. 패시브

    숲 속의 로맨스

    쿨다운 0 · 소모 0

    처벌은 석방으로 대체됩니다. 해방 후 야생 몬스터는 그녀에게 금화와 경험치를 주게 되며, 야생 몬스터의 보조 효과도 얻게 됩니다. 그녀가 영웅이나 구조물을 공격할 때마다, 그녀의 동물 동료는 이동 속도가 증가하고 대상을 함께 공격합니다. 동물 동료는 타워에 기본 피해의 50%만 줍니다. 阿古朵은 새총 기본 공격을 사용하여 (100% 물리 공격) 물리 피해를 입힙니다.

    물리 피해
  2. 1스킬

    야생 성장

    쿨다운 14 · 소모 0

    덤불을 심으면 해당 지역에 있는 아군(군인 제외)의 이동 속도가 30/34/38/42/46/50% 증가하고 0.5초마다 체력이 30/36/42/48/54/60 회복됩니다. 阿古朵과 그녀의 소환수들은 치유량이 2배로 증가하고, 해당 지역의 공격 속도가 30/36/42/48/54/60% 증가합니다. 해당 지역에 있는 적은 10% 느려지고 3초 동안 그 안에 있으면 1초 동안 움직이지 못하게 됩니다. 패시브: 방출된 도마뱀의 수가 2/4/6마리를 초과하면 소형/중형/대형 도마뱀이 소환되어 도움을 줍니다.

    회복둔화소환/분신광역
  3. 2스킬

    공을 굴려라

    쿨다운 13 · 소모 0

    구르고 돌진하여 0.25초마다 주변에 40/48/56/64/72/80(+1.5% 최대 체력)의 물리 피해를 입힙니다. 돌진 후 돌진하여 닿는 적에게 120/144/168/192/216/240(+최대 체력의 4.5%)의 물리 피해를 입힙니다. 동일한 대상을 여러 번 타격할 경우, 충전 피해가 75%로 감소됩니다. 충전시간이 길어질수록 충전거리는 늘어납니다. 전체 시전 기간 동안 1회 하드 컨트롤 효과에 면역이 가능하며, 시전 수행 쿨다운 70%를 취소한다. 패시브: 방출된 꿩의 수가 2/4/6마리를 초과하면 처음으로 적에게 돌격하는 지점 또는 종료 지점에서 전투를 돕기 위해 소형/중형/대형 꿩이 소환됩니다.

    물리 피해기동체력 비례소환/분신
  4. 3스킬

    캐니언 밸리

    쿨다운 40/33/26 · 소모 0

    추추는 阿古朵을 떠나 지정된 위치로 돌진해 450/750/1050(+70% 물리 공격력)의 물리 피해와 공중 띄우기 효과를 준 후 혼자 싸운다. 주문 시전 후 폭발 폭탄의 쿨다운이 초기화되고 공의 체력이 최소 10% 이상 회복됩니다. 동시에 阿古朵은 최대 체력의 25%로 회복됩니다. 주문을 시전하면 자신에 대한 제어 효과가 해제되고, 다시 주문을 시전하면 공을 리콜할 수 있습니다. 패시브: 해방된 산악 영웅과 치타의 수가 2/4/6개를 초과하면 소형/중형/대형 산악 영웅과 치타가 소환되어 전투를 지원합니다. 방출된 붉은색 석상과 하늘색 석상의 개수가 2/3/4개를 초과하면 공의 공격 효과가 다양한 정도로 강화됩니다. 지속 효과: 球球의 이동 속도가 10/20/30% 증가하고 공격 속도가 30/45/60% 증가하며 1500/2500/3500 생명 보호막을 얻습니다.
