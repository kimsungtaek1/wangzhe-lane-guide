상대 특성

마법 사수 계열. 마법 평타와 이동으로 거리를 유지하며 지속 딜을 넣는다.

마법 사수마법 피해둔화치명타표식중첩/강화광역

라인전 대응

아이린의 평타 사거리 밖에서 미니언을 먹고, 이동기가 빠진 뒤 2스킬로 접근한다.

교전·한타

아군 딜러와 함께 아이린을 측면에서 압박하고, 붙은 뒤 점사한다.

하지 말 것

아이린의 이동 경로를 따라가며 스킬을 낭비하는 것.

  1. 패시브

    精灵舞步

    쿨다운 0 · 소모 0

    艾琳普攻命中敌人后造成150(+20%法术攻击)法术伤害，并获得能量，能量满后艾琳消耗能量急速飞行。 能量满后艾琳获得一次强化普攻，对首个命中的目标造成180(+30%法术攻击)法术伤害。 艾琳每100点法术攻击可以转化为1%暴击率。

    마법 피해치명타중첩/강화
  2. 1스킬

    叶舞·致意

    쿨다운 7 · 소모 0

    艾琳射出一束月桂叶，对命中的目标造成法术伤害，并且第一段命中目标增加一层月桂印记，命中敌方英雄或飞行到最远处后展开成环，对触碰的敌人造成法术伤害和50%减速，持续1秒。

    마법 피해둔화표식
  3. 2스킬

    旋舞·轻语

    쿨다운 10/9.2/8.4/7.6/6.8/6 · 소모 0

    艾琳受到黄金森林的祝福，立即回满能量，同时叠加两层月桂印记，获得免疫减速效果并增加30/34/38/42/46/50%攻速，持续3秒。

    둔화표식중첩/강화
  4. 3스킬

    月桂之舞·盛放

    쿨다운 20/17.5/15 · 소모 0

    艾琳能量满后会叠加一层月桂印记。当月桂印记达到6层时【月桂之舞·盛放】解锁，印记叠加上限为12/15/18层。技能开启时，艾琳增加10%移速，不断消耗印记发出月桂飞叶，对范围内血量最少的目标造成80/110/140(+22%法术攻击)法术伤害，并减少【旋舞·轻语】0.2秒的冷却时间。

    마법 피해표식중첩/강화광역
