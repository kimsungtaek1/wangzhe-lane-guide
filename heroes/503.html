狂铁

공식 대항로 후보에너지 보호막 전사对抗路

한 줄: 에너지가 낮을 때 싸우고, 강화 후엔 빠진다.

← 对抗路 얼굴 목록으로

상대 특성

물리 에너지형 전사. 에너지가 찬 상태의 보호막·회복·강화 기술로 긴 교전을 이기고, 에너지가 낮으면 약해진다. 강화 기술 사용 후 빈틈이 크다. 에너지 게이지와 강화 타이밍이 핵심.

에너지 보호막 전사물리 피해보호막회복기동강제 제어둔화체력 비례중첩/강화광역

핵심 위협

에너지가 찬 상태의 보호막·회복·강화 기술로 긴 교전을 이긴다.

라인전 대응

에너지가 낮을 때 교환하고, 강화 기술이 빠진 뒤 거리를 벌린다. 에너지가 가득 찬 상태에서는 강화 평타만 넣고 빠진다.

단계별 운영

1~3레벨: 에너지가 낮을 때 교환하고, 강화 기술이 빠진 뒤 거리를 벌린다. 4~5레벨: 에너지가 가득 찬 상태에서는 강화 평타만 넣고 빠진다. 중후반: 아군 딜러에게 강화 진입을 허용하지 않고, 강화 후 점사한다.

교전·한타

아군 딜러에게 강화 진입을 허용하지 않고, 강화가 끝난 뒤 2스킬로 붙잡는다.

킬각·교환

광철이 에너지를 채우고 들어오면 일단 빠져 강화 기술을 허공에 쓰게 하고, 강화가 끝난 직후 2스킬로 붙잡는다. 에너지가 가득 찬 상태의 긴 맞딜은 금지.

빌드·운영

抵抗之靴, 红莲斗篷, 不祥征兆. 치유 감소로 회복을 줄인다.

하지 말 것

에너지가 가득 찬 광철과 긴 맞딜을 하는 것.

  1. 패시브

    无畏战车

    쿨다운 0 · 소모 0

    被动：狂铁的武器在击中敌人时会激发电流，进而为武器充能。普攻每命中一个英雄/非英雄回复7点/5点能量，技能命中敌方单位回复10点能量，普攻命中敌方单位回复7点能量，不再区分单位类型，最多可储存90点能量。充能≥30点时，技能会获得不同的强化效果，每次普攻附带50点物理伤害，并在命中敌人时回复70点自身生命值。强化技能使用时会消耗30点能量，且不会因击中敌人而获取能量。脱离战斗后，能量不再随时间衰减。

    물리 피해중첩/강화
  2. 1스킬

    碎裂之刃

    쿨다운 5 · 소모 0

    狂铁奋力向前横挥武器两次，每次造成80/110/140/170/200/230(+100%物理加成)点物理伤害。每命中一个敌人回复自身已损生命值2%+30/36/42/48/54/60（+16%物理加成）点生命值。充能强化：伤害提升至120/165/210/255/300/345（+150%物理加成）点物理伤害，生命回复提升至已损生命值4%+60/72/84/96/108/120（+32%物理加成）点生命值。

    물리 피해회복체력 비례중첩/강화
  3. 2스킬

    强袭风暴

    쿨다운 10/9.6/9.2/8.8/8.4/8 · 소모 0

    狂铁向前冲锋，冲锋路径上的敌人受到150/180/210/240/270/300(+75%物理加成)点物理伤害。冲锋结束后，狂铁的下次普攻得到强化，造成200/240/280/320/360/400（+100%物理加成）点物理伤害和50%减速效果持续2秒。充能强化：在释放强化普攻时若能量＞30，强化普攻伤害提升至300/360/420/480/540/600（+150%物理加成）点物理伤害，对受击者造成1秒击飞和晕眩，以及之后1秒50%减速。且在释放第一次强化普攻时消耗30点能量。

    물리 피해기동강제 제어둔화중첩/강화
  4. 3스킬

    力场压制

    쿨다운 15/13/11 · 소모 0

    将武器砸向地面，造成250/375/500（+100%物理加成）点物理伤害和1.5秒50%减速。同时生成1000/1500/2000点护盾，持续六秒。充能强化：伤害提升至325/485/645（+140%物理加成）点物理伤害，护盾值提升至1500/2250/3000。同时会制造一道电弧，对敌方单位造成70（+70%物理加成）点物理伤害，并从每个英雄窃取20/35/50点移速赋予狂铁。电弧的范围会随三技能等级逐渐扩大。

    물리 피해보호막둔화중첩/강화광역
