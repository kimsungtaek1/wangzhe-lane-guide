상대 특성

물리 연계 선택형 전사. 연속 기술 선택으로 당기기·차기·회복을 바꾸며 콤보를 만든다. 콤보가 끝나며 뒤로 빠지는 구간이 빈틈이고, 첫 동작을 보고 대응해야 한다. 콤보 선택과 종료 타이밍이 핵심.

연계 선택 전사물리 피해회복강제 제어둔화면역/해제광역

핵심 위협

연속 기술 선택으로 당기기·차기·회복을 바꾸며 콤보를 만든다.

라인전 대응

첫 동작에 반응해 스킬을 전부 쓰지 말고, 콤보가 끝나며 뒤로 빠지는 구간을 압박한다. 당기기 사거리 밖에서 미니언을 정리한다.

단계별 운영

1~3레벨: 첫 동작에 모든 스킬을 쓰지 말고, 콤보가 끝나는 구간을 압박한다. 4~5레벨: 당기기 사거리 밖에서 미니언을 정리하고, 종료 후 2스킬로 붙잡는다. 중후반: 아군 딜러를 당기는 콤보를 끊고 점사한다.

교전·한타

아군 딜러를 당기는 콤보를 끊고, 콤보 종료 후 2스킬로 붙잡는다.

킬각·교환

키소만이 콤보를 시작하면 첫 동작을 보고 뒤로 빠져 허공에 쓰게 하고, 콤보 종료 직후 2스킬로 붙잡는다. 첫 동작에 모든 스킬을 쏟지 않는다.

빌드·운영

抵抗之靴, 红莲斗篷, 不祥征兆. 闪现로 당기기를 피한다.

하지 말 것

키소만의 첫 동작에 모든 스킬을 쏟는 것.

상세 스킬

4개

중국판 공식 스킬 설명입니다. 스킬명·쿨다운·수치는 패치에 따라 달라질 수 있으므로 게임 내 최신 설명을 우선하세요.

  1. 패시브

    稍微摸鱼一下

    쿨다운 0 · 소모 0

    小满使用技能会消耗力劲（拳劲和腿劲），所以稍不留神她就会坐下摸鱼，增加25%力劲值的回复速率，期间小满还会掏出各式零食，随机回复80（+20%物理攻击）的1倍、1.5倍、2倍生命。

  2. 1스킬

    随变一式

    쿨다운 9(-0.4/Lv) · 소모 0

    小满跑步向前，将前方敌人拉拽到自己身前造成物理伤害。 遇弱则进：在技能后短暂时间内使用【随变一式】，小满腾空跃起后劈出势大力沉的一击，对范围内敌人造成物理伤害和击飞。 以进为退：在技能后短暂时间内使用【随变二式】，小满打出行云流水的拳脚连招，造成物理伤害并回复自身生命。

    물리 피해회복강제 제어광역
  3. 2스킬

    随变二式

    쿨다운 9(-0.4/Lv) · 소모 0

    小满翻身向前，灵巧闪过敌人攻击，期间小满处于霸体状态，减少所受伤害，并回复生命。 遇强则离：在技能后短暂时间内使用【随变二式】，小满飞踢向敌人造成物理伤害并回复生命，随后借力翻身跃向空中，期间不可被选中并回复生命。 强攻代守：在技能后短暂时间内使用【随变一式】，小满瞬移至敌人身后施展回旋踢，击退目标并造成物理伤害，成功击败目标可回复生命和力劲。

    물리 피해회복강제 제어면역/해제
  4. 3스킬

    稍微认真一点

    쿨다운 60(-5/Lv) · 소모 0

    进入认真状态后，小满立即回复一格拳劲和腿劲，并将力劲储存上限提升为3格，期间小满获得加速并减少50%所受到的减速效果，该状态持续10秒。
