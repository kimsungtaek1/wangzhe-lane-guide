芈月

상대 특성

마법 흡혈형 지속 전사. 연결 흡혈과 무적 궁극기로 긴 교환을 이기고, 체력이 낮아도 시간을 벌어 역전한다. 폭발적인 순간 딜은 낮지만 지속력이 매우 높다. 연결이 끊기거나 궁극기가 빠지면 급격히 약해진다.

흡혈 지속 전사마법 피해회복소환/분신중첩/강화광역

핵심 위협

연결 흡혈과 무적 궁극기로 긴 교환을 이긴다. 체력이 낮아도 궁극기로 시간을 벌며 역전한다.

라인전 대응

연결이 붙은 상태에서 맞딜하지 않는다. 연결을 끊고 거리를 벌린 뒤, 궁극기가 빠진 타이밍에 강화 평타로 압박한다. 초반에는 미니언을 끼고 사거리를 유지한다.

단계별 운영

1~3레벨: 연결이 붙은 상태에서 맞딜하지 않고, 연결이 끊긴 뒤 짧게 교환한다. 4~5레벨: 궁극기 무적을 보고 스킬을 쏟지 말고, 착지 후 2스킬로 붙잡는다. 중후반: 아군 딜러에게 연결이 붙으면 즉시 끊고, 치유 감소를 유지한다.

교전·한타

아군 딜러에게 연결이 붙으면 즉시 끊는다. 무적 궁극기 동안 추격하지 말고, 착지 후 2스킬로 붙잡는다.

킬각·교환

미월이 연결을 걸고 들어오면 일단 거리를 벌려 연결을 끊고, 궁극기로 무적이 된 뒤 착지 지점을 예측해 2스킬을 맞춘다. 무적이 끝난 직후가 유일한 킬각이다.

빌드·운영

抵抗之靴, 红莲斗篷, 永夜守护. 치유 감소를 요청하고 마법 비중에 맞춰 魔女斗篷.

하지 말 것

무적 궁극기를 보고도 계속 스킬을 쏟아붓는 것.

상세 스킬

4개

  1. 패시브

    永生之血

    쿨다운 0 · 소모 0

    被动：芈月释放技能会召唤暗影仆从并对附近的敌人进行攻击，每次攻击会造成50（+7%法术加成）点法术伤害，对小兵额外造成80（+14%法术加成）点法术伤害，对野怪额外造成40（+7%法术加成）点法术伤害，并回复25（+3%法术加成）点生命值；召唤暗影仆从时芈月获得30点暗影之力，暗影之力会为芈月增加移速和治疗效果，最多增加30点移速和10%治疗效果，暗影之力消失时暗影仆从也会立即消失；暗影仆从最多存在6个。

    마법 피해회복소환/분신
  2. 1스킬

    痛苦冲击

    쿨다운 10/9.6/9.2/8.8/8.4/8 · 소모 0

    芈月向指定方向释放暗影能量，对路径上的敌人造成200/220/240/260/280/300（+24%法术加成）点法术伤害；在暗影能量飞行的过程中，芈月能够再次使用技能降临在暗影能量位置，并对范围内敌人造成200/220/240/260/280/300（+24%法术加成）点法术伤害；第二段技能命中敌人会为芈月召唤一个暗影仆从。

    마법 피해소환/분신광역
  3. 2스킬

    幻翼仆从

    쿨다운 9 · 소모 0

    芈月向指定方向释放暗影锁链，锁链将会和第一个命中的敌人连接，最多持续4秒；连接后每0.5秒抽取目标10点物理攻击力与30点法术攻击力，并对敌人减少2.5%移动速度，最多可以减少20%移动速度，每次抽取目标将回复自身15（+2%法术加成）点生命值并造成25/36/47/58/69/80（+7%法术加成）点法术伤害；如果连接持续4秒，会为芈月召唤一个暗影仆从；双方超过一定距离会挣脱连接。被动：芈月普通攻击得到强化，造成40（+100%物理加成）（+20%法术加成）点法术伤害并减少其10%移动速度，同时增加自身10点暗影之力。

    마법 피해회복소환/분신중첩/강화
  4. 3스킬

    暗影之月

    쿨다운 24/22/20 · 소모 0

    芈月遁入暗影，增加30%移动速度并免疫所有效果，持续2秒；技能开启及结束时都将对范围内的敌人造成400/500/600（+50%法术加成）点法术伤害；如果第二段伤害命中敌人，会为芈月召唤一个暗影仆从；
