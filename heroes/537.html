司空震

한 줄: 궁극기 착지 후 강화가 끝날 때.

상대 특성

마법 원거리/근접 전환 전사. 원거리 견제와 근접 연속 공격, 궁극기 진입을 함께 한다. 궁극기 강화 중에는 폭딜과 생존이 강하고, 강화가 끝나면 약해진다. 궁극기 착지와 강화 시간이 핵심.

원거리/근접 법사 전사마법 피해보호막강제 제어면역/해제형태 전환중첩/강화광역원거리

핵심 위협

원거리 견제와 근접 연속 공격, 궁극기 진입을 함께 한다.

라인전 대응

사거리 안에서 기술을 다 맞지 말고, 궁극기 착지 뒤 강화 시간이 빠질 때 대응한다. 원거리에서는 미니언 뒤에서 버틴다.

단계별 운영

1~3레벨: 사거리 안에서 기술을 다 맞지 말고, 미니언 뒤에서 버틴다. 4~5레벨: 궁극기 착지 뒤 강화 시간이 빠질 때 대응한다. 중후반: 아군 딜러를 보호하고, 착지 후 2스킬로 붙잡는다.

교전·한타

궁극기로 들어오면 아군 딜러를 보호하고, 착지 후 2스킬로 붙잡는다.

킬각·교환

사공진이 궁극기로 들어오면 착지 지점을 피하고, 강화가 끝난 직후 2스킬로 붙잡는다. 강화 중 정면 맞딜은 금지.

빌드·운영

抵抗之靴, 永夜守护, 魔女斗篷. 마법 피해에는 魔女.

하지 말 것

궁극기 강화 중인 사공진과 정면으로 맞딜하는 것.

  1. 패시브

    天雷引

    쿨다운 0 · 소모 0

    司空震的普通攻击造成140（+30%物理攻击）（+25%法术攻击）法术伤害。近距离会触发近战攻击，攻击间隔降低。普攻获得1点天雷之力，上限6点。达到上限时引动天雷，获得一次额外释放基础技能的机会。释放基础技能后，获得强化普攻，对大范围内敌人造成300(+25%法术攻击)法术伤害。远程强化普攻锁定目标以外单位受到75%伤害，不触发法球效果。

    마법 피해중첩/강화광역원거리
  2. 1스킬

    奔雷疾

    쿨다운 10/9.6/9.2/8.8/8.4/8 · 소모 0

    司空震化身奔雷向前疾行，对路径上敌人造成180/216/252/288/324/360(+20%法术攻击)法术伤害并获得210/235/260/285/310/335(+10%法术攻击)点护盾，持续2秒。

    마법 피해보호막
  3. 2스킬

    狂雷击

    쿨다운 13/12.6/12.2/11.8/11.4/11 · 소모 0

    司空震向前释放出一道狂雷之力，达到最大射程，或触碰到单位短暂延迟后爆炸，造成击退和250/300/350/400/450/500(+30%法术攻击)法术伤害。离司空震距离越近的单位被击退得越远。

    마법 피해강제 제어원거리
  4. 3스킬

    雷霆万钧

    쿨다운 70/60/50 · 소모 0

    司空震升入空中，化身为雷霆之王。 变身过程持续1.5秒，期间获得霸体，增加30%移动速度，无视地形阻挡，并让五个雷鼓依次随机轰击附近敌人（优先英雄）。每次雷击造成80/100/120(+4%法术攻击)法术伤害，并使司空震获得1点天雷之力和180/210/240(+10%法术攻击)点护盾，持续1秒。落地时对附近敌人造成360/540/720(+35%法术伤害)法术伤害。 变身持续10秒，期间普攻改为获得2点天雷之力，远程普攻会产生雷电链，在多个敌人间弹射，造成100/150/200(+10%法术攻击)法术伤害。强化普攻的范围增加。

    마법 피해보호막면역/해제형태 전환중첩/강화광역
